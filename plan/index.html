話し方

方言は言葉づかいが変わります（アクセントは読み上げの声のままです）。外国人風はカタコトの日本語で話し、英語の声があれば英語のひとことと数字が入ります。

セリフ

AIはトレーニングの日に1回だけ、その日のメニューに合わせたセリフ一式を作ります（1回あたり約2,000トークン、初回は利用の確認が出ます）。作れないときは定型のセリフを使います。

スマホに入っている日本語の声から選べます。

高音質の声を入れる
iPhone・iPad
  1. 「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」
  2. 「日本語」→「Kyoko」（または Otoya／Hattori／O-ren）
  3. 「拡張」か「プレミアム」をダウンロード（数百MB、Wi-Fi推奨）
  4. このページに戻って「声を読み込み直す」

声の一覧を取得できない画面でも、ここで日本語の「声」に選んだ声が標準の声として使われることがあります。

Android
  1. 「設定」→「一般管理」（または「システム」）→「言語と入力」→「テキスト読み上げ」
  2. 優先エンジン「Googleの音声サービス」の⚙ →「音声データをインストール」
  3. 「日本語」→ 高品質（またはネットワーク）の声をダウンロード
  4. このページに戻って「声を読み込み直す」

このアプリに声を入れることはできません。スマホの読み上げの声を使います。
